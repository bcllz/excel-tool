# 📊 Excel 百宝箱

10 合 1 智能 Excel 处理工具，浏览器打开就能用。

**🔒 隐私安全：所有数据在本地内存处理，不上传任何服务器。**

---

## 🚀 怎么用

### Windows 用户（推荐 — 直接用 EXE）

> 无需安装 Python！直接双击运行。

1. 下载 `Excel百宝箱.exe`
2. **双击运行**（首次启动需要 10-20 秒）
3. 浏览器会自动打开 `http://localhost:8501`
4. 上传 Excel → 选功能 → 处理 → 下载结果
5. 用完关闭弹出的黑色窗口即可

> ⚠️ 运行中**不要关闭黑色窗口**，关了程序就停了。
>
> ⚠️ 杀毒软件可能会弹警告（因为 exe 是自打包的），选择「允许运行」即可。

---

### Windows 用户（备选 — 用 Python 跑）

> 适用场景：无法运行 exe，或想自己改代码。

1. 确认电脑装了 **Python 3.9+**
   - 没装的话去 https://www.python.org/ 下载
   - 安装时勾选 ✅ **Add Python to PATH**
2. 双击 `start.bat`
3. 浏览器打开 `http://localhost:8501`

---

### Mac 用户

1. 确认装了 Python 3.9+（终端输入 `python3 --version` 检查）
2. 双击 `start.sh`，或在终端里输入 `bash start.sh`
3. 浏览器打开 `http://localhost:8501`

> 首次启动需几分钟下载依赖，之后秒开。

## ❓ 常见问题

**Q: EXE 打开后没反应？**
A: 等 10-20 秒后再看浏览器。如果还没开，手动打开浏览器输入 `http://localhost:8501`

**Q: 浏览器显示「无法连接」？**
A: 确认黑色窗口还在（没关掉），端口可能变了，看黑色窗口里显示的地址。

**Q: Windows 提示「Windows 已保护你的电脑」？**
A: 点击「更多信息」→「仍要运行」。这是自打包程序的正常现象，不是病毒。

**Q: pip 安装很慢？**
A: 脚本已内置国内镜像加速。如果还是慢，关了代理/VPN 再试。

**Q: 想自己改代码怎么办？**
A: 编辑 `app.py`，保存后重启即可。代码有中文注释，改着不费劲。
